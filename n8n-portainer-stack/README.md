## ⚠️ Things to Know Before Deploying

1. **Database dependency:** This stack includes `n8n-postgres`. Ensure the database container is healthy before starting dependent services.
2. **Restart policy:** `unless-stopped` — containers will restart automatically unless explicitly stopped.
3. **Custom networks:** This stack defines custom networks (`default, trading-net-ron`). Other stacks sharing these networks can communicate directly.
